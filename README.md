# Fidget Shooter Releases

Public distribution channel for protected stable Fidget Shooter builds.

## v41.52

[Download the playable HTML](https://raw.githubusercontent.com/minhhuy030309-rgb/fidget-shooter-releases/main/latest.html) and open the saved file in your browser. Choose Solo Duel, then **Gunslinger · Free Roam Prototype** to enter the campaign.

This release adds the Crossroads campaign prototype, local progress saves, ammunition presets, inventory, healing supplies, exploration combat, dialogue and embedded campaign music. The original solo routes and multiplayer remain available. It also brings the prior v41.50/v41.51 Green Lantern, Frieren and Black Flash updates to the public channel.

Multiplayer uses **protocol 88**; both players need compatible files. Campaign progress stays local to the browser/device. The Waystation supplies and ammunition grants are part of the prototype's testing content.

Music attribution and license links are in campaign Settings → Credits. Development source and history live in the private `fidget-shooter` repository.
